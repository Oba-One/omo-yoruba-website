# Odunde is one word

Decided by the owner on 1 September 2026: the festival is written "Odunde" as one word in
all display text, with marks in the nav ("Ọdúndé Festival"), and lowercase `odunde` in
URLs and file names. The design system readme in `docs/design/design/_ds/` still spells it
as two words; this decision overrides it, and `packages/lint/yoruba-terms.json` maps the
two-word form to the one-word form so the lint and the Studio validation both catch it.
