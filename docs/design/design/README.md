# Design references

Prototypes and assets copied from the design project on 4 September 2026.
Open any `.dc.html` in a browser from this folder (they load `support.js`, the
`_ds/` design system, `oy-components.css` and `images/` by relative path).

- `Omo Yoruba Site.dc.html`: the whole site with page switching.
- `01 Components.dc.html`: the component canvas, every variant and state.
- `02 Homepage.dc.html`: the fidelity bar.
- `06 Site Wireframes.dc.html`: the approved plan, sitemap plus eleven pages.
- `07 Interaction Inventory.dc.html`: the fourteen interactions, binding.
- `08` to `18`: the built pages (17 News & Events was never built).
- `19 Mock Content Register.dc.html`: what is invented and what is confirmed.
- `Enquiry Modal`, `Give Dialog`, `Photo Carousel`, `Site Nav`, `Site Footer`:
  shared parts.
- `08 Build Brief.md`: the brief the pages were built from, with three polish
  passes recorded at the end.
- `oy-components.css`: the shared interaction layer; wins over `_ds/` where they
  conflict.
- `_ds/`: the design system tokens, base and component CSS, readme, and React
  bundle (reference only).
- `images/`: real photographs (`w2/` are web-sized copies), the logo mark and
  lockup, pattern SVGs. Credits are unconfirmed; see the register.
