# Content model for Sanity

Owner: `packages/content`. Every type is `defineType`, every query is
`defineQuery` with a unique constant name, types generated by Sanity TypeGen.
Studio structure pins singletons first. Sources: `design/19 Mock Content
Register.dc.html` (what is invented, what is confirmed), each page prototype,
`design/Enquiry Modal.dc.html`.

## 1. Principles

1. **Confirmed facts only in the seed.** The only facts the client has supplied:
   501(c)(3) since 1997; Los Angeles; the Odunde Festival at Leimert Park each
   June; the End-of-Year Gala in November or December; Yoruba Language Lessons
   taught online by one teacher, enrolment by writing to her; the Yoruba Cultural
   Collective with Solar Hub and Green Goods; Kids & STEM including Àgbàlá Ọmọde
   and the STEM Hub; Cultural Exchange; four festival zones (two named: Ọjà
   Balógun the market, Àgbàlá Ọmọde the children's yard); nine hometown
   associations; 3,000+ community; 29 years; the three real homepage news posts;
   the photographs in `design/images/`. EIN is "XX-XXXXXXX" until supplied.
2. **Empty means pending.** No `placeholder: true` flags. A required-for-launch
   field that is empty renders a `<Pending what="2027 festival date" />` chip on
   the site (design system placeholder style) and appears in the Studio Pending
   dashboard. The Mock Content Register becomes that dashboard.
3. **Bilingual micro-moments are structured.** Kickers are an object
   `{ yo: string, en: string }` rendered "yo • en". Zone names carry Yoruba with
   marks plus an English translation. Never a free-text string that mixes both.
4. **Layout options live with the page.** Every tweak prop from the design is a
   field on the page singleton's `layout` object (see ROUTES doc section 5).
5. **One primary action per page.** Page singletons have one `primaryAction`
   (label, kind: enquiry kind | give | url). Secondary actions are a separate
   array and render as outline buttons. The schema shape enforces the gold rule.
6. **Every image has alt, caption, and credit.** `oyImage` object: asset with
   hotspot, `alt` (required), `caption` (Yoruba-first allowed), `credit`
   (reference to `photographer` or free text), `creditConfirmed` boolean.
7. **Portable Text is minimal.** Blocks: normal, h3, blockquote; marks: strong,
   em, link. No embedded objects in body copy except `pullQuote`. Rendered with
   `astro-portabletext`.
8. **Validation encodes the voice.** Custom rules on every string and text
   field: no em dash (error), Yoruba glossary term without marks (warning),
   headings and button labels in sentence case (warning). Alt required (error).

## 5. Studio structure

```
Pages          siteSettings, homepage, festivalPage, galaPage, programsPage,
               lessonsPage, collectivePage, getInvolvedPage, impactPage,
               storyPage, donatePage, gallerySettings, newsPage
Events         event (by kind, upcoming first), zone, ticketTier, sponsorLevel, honoree
Programs       program, initiative, faq, givingLevel
People         person (by group), testimonial, photographer, partner, hometownAssociation
Impact         stat, outcome, governanceDoc, timelineEntry
News           newsPost
Gallery        album
Inbox          enquiry (by kind, unhandled first), subscriber
Pending        custom list: every document with an empty required-for-launch field
```

The **Pending** view is a GROQ-driven document list (one query per type using
`!defined(field)` on the fields marked pending in this doc) with a short
description per row of what is missing, mirroring `19 Mock Content Register`.

Presentation tool: `previewUrl` from env, `locations` resolver mapping every
singleton and document type to its route(s), `mainDocuments` for each route.

Roles: owner is Administrator. Org members are Editors restricted from
`siteSettings` and `enquiry` through document actions and structure visibility
(Sanity roles are plan-dependent; document-level hide is the fallback).

## 6. Seeding (Phase 2)

`packages/content/scripts/seed.ts`, run once per dataset with the write token.

- Creates every singleton with the confirmed facts and empty pending fields.
- Uploads every file in `design/images/w2/*.jpg` (web-sized) as assets, one
  `album` per set: "Odunde 2026" (Red Carpet Media, `creditConfirmed: false`),
  "End-of-Year Gala 2025" (Members and volunteers, unconfirmed), "Summer camp"
  (Omo Yorùbá archive, year unstated, unconfirmed). Captions come from the
  register's descriptions. Alt text is the caption until reviewed.
- Creates the four `stat` documents: 29 years, 3,000+ community, 5 festival zones
  (note: register says four zones are confirmed; use 4 and mark the fifth
  pending), 9 hometown associations.
- Creates the four `program` documents and the two `initiative` documents with
  status empty.
- Creates the two named `zone` documents (Ọjà Balógun, Àgbàlá Ọmọde) with lines
  empty; two unnamed zone slots are not created.
- Creates `event` documents for Odunde 2027 and Gala 2026 with dates empty.
- Creates the three real homepage news posts (copy from `02 Homepage.dc.html`).
- Creates `photographer` documents.
- Does **not** create any person, partner, testimonial, timelineEntry, faq,
  ticketTier, sponsorLevel, honoree, givingLevel or hometownAssociation. The
  site renders named placeholders for each block until the owner adds them.

Idempotent: uses deterministic `_id`s so re-running updates rather than duplicates.

## 7. Content operations with AI

The owner adds content from Claude Code through the Sanity MCP server
(`.mcp.json` → `https://mcp.sanity.io`, OAuth). Write these into the repo skill
`oy-content-ops` (see AGENT-DOCS.md) so a session knows the recipes:

- **New news post**: create `newsPost` draft with title, slug, date, bilingual
  kicker (Yoruba with marks, English), summary, body, image from an existing asset
  or a new upload with alt and credit, tags. Run the voice check. Publish, or leave
  as draft for review.
- **New event edition**: create a Content Release named for the edition; inside
  it create the `event`, tiers or zones, schedule items; update the page
  singleton's `glance`; publish the release on the announce date.
- **New album**: upload photos, create `album` with cover, photos with alt and
  captions, credit and `creditConfirmed`, link to its `event`.
- **Add a person**: `person` with group and order; portrait optional.
- **Clear pending**: open the Pending view (or query it), fill the field, confirm
  the chip disappears on the site.
- **Never** invent a figure, price, date, name or quote. If the owner asks for
  copy, draft it in the voice and mark the document as draft for their review.
- Agent Actions (Generate, Transform) are opt-in and owner-triggered; they use AI
  credits. Use for alt text drafts and Yoruba kicker suggestions only.

Webhook: on publish of any document, POST to `/api/revalidate` with the document
type and slug; the route purges the cache tags for affected routes.
